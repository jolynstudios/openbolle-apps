# Your first Python server app

This starter gives Bolle one tool and one screen, both called `hallo`. Open a terminal in this folder. Install Node.js 22 or newer and Python 3, then run:

```sh
npx github:jolynstudios/openbolle-apps controleer
npx github:jolynstudios/openbolle-apps dev
```

Open the address the command prints. Call `hallo` and try **Zeg hallo** on the sample screen. Change the response in `plugin.py`. If you rename a tool or a block, update `app.yaml` as well.

The screen shows a value, a ring and a button. To try an alert, enable `proefmelding` in the preview settings. Remove unused permissions when you adapt the starter. See the [development guide](https://openbolle.nl/docs/ontwikkelen/) for checks and device testing.

# Mijn accessoire

Bolle laat de pushmeldingen van een app op je telefoon zien als zijn eigen meldingen.

## Installeren

1. Voeg de winkel toe: open **Instellen** op de site van openBolle, kies **Apps → Andere winkels** en plak het adres van de winkel. Vergelijk de code van de winkel en kies **Vertrouwen**.
2. Installeer **Mijn accessoire** op Bolle via **Menu → Apps → Nieuwe app**.

## Koppelen

Koppel je iPhone met Bolle in **Instellingen → Bluetooth** en sta toe dat Bolle meldingen mag zien.
